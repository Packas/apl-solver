# APL Shove Tools

Two pages for the APL Million tournament, built from a push/fold solver.

- `index.html` is the solver. It shows payments left, a blind clock, a chip counter and shove or call charts.
- `trainer.html` is the practice site. It drills shove or fold, call or fold, and counting chips into payments.

The pages share the table-size setting on the same device. Everything else stays on your phone. There is no server.

To update a page, upload a new copy with the same file name in GitHub (Add file, then Upload files).
The charts are chip-EV push/fold ranges for stacks from 1.5 to 20 big blinds. They ignore payouts and multiway pots.
